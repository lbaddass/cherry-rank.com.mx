# Cherry Rank — Architects of Authority

## Contexto
Firma de alto impacto especializada en crecimiento orgánico y sistemas de adquisición SEO + IA para el mercado LATAM/México.

## Stack Tecnológico (Vercel Ready)
- Framework: Next.js (Performance-first)
- Estética: Neo-minimalismo funcional (Off-white & Carbon)
- Pagos: Sistema de validación manual SPEI / WhatsApp Business

## Estructura del MVP (V1)
1. **Home**: Filtro de autoridad y puntos de dolor.
2. **Catalog**: Servicios de activación inmediata (Self-service).
3. **Specialized**: Landing específica para Clínicas de Salud y Sector Político.
4. **Checkout**: Pantalla de confirmación de transferencia bancaria.

## Configuración para Vercel
Para asegurar que el dominio cherry-rank.com.mx vuele, configura estos parámetros en Vercel:
- Framework Preset: Next.js.
- Build Settings: Optimización de imágenes automática.
- Environment Variables: `NEXT_PUBLIC_WHATSAPP_NUMBER` para el flujo de ventas.
